Stackelberg Security Game — Aircraft Patrol Planning

Implements the three-stage algorithm from "A Stackelberg Security Game Formulation for Aircraft Patrol Planning": Stage 1 (optimal flying-hour allocation), Stage 2 (mixed strategy via a feasibility LP), Stage 3 (concrete patrol timetables + aircraft assignment), plus the minimum-fleet-size result and a comparison against four baseline patrol policies.
